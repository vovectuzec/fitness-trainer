# Fitness Trainer

## Опис
Gрограмне забезпечення системи Онлайн-супроводу фітнес-тренувань.

## Технології
- Python
- SQLite
- Telegram Bot API

## Запуск
1. Встановити Python 3.11.9
2. Встановили Visual Studio Code та налаштувати її
3. Запустити fitness_telegram_bot.py
