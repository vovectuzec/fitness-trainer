# Production Deployment

## Архітектура проєкту

Проєкт включає:

- Telegram Bot API
- Python application server
- SQLite database
- APScheduler для нагадувань

## Мінімальні системні вимоги

- CPU: 1 core
- RAM: 2 GB
- Disk: 2 GB
- ОС: Windows/Linux

## Необхідне ПЗ

- Python 3.12+
- pip
- Git

## Налаштування мережі

Потрібен доступ до:
- api.telegram.org
