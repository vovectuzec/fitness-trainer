# Backup Guide

## Стратегія резервного копіювання

Використовується:
- повне резервне копіювання SQLite;
- резервне копіювання конфігурацій;
- резервне копіювання документації.

## Частота backup

- база даних: щоденно;
- конфігурації: після змін;
- код: через GitHub.

## Backup бази даних

```bash
copy fitness_bot.db backup/fitness_bot_%date%.db
