# Логування та обробка помилок

## Обраний підхід

У проєкті Fitness Trainer використовується стандартний модуль Python `logging`.

## Рівні логування

- DEBUG — детальна діагностична інформація.
- INFO — запуск і штатні події програми.
- WARNING — некоректні дії користувача.
- ERROR — помилки виконання окремих операцій.
- CRITICAL — критичні помилки, які можуть зупинити систему.
