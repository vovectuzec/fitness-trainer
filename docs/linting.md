# Linting

## Обрані інструменти

Для проєкту Fitness Trainer використано такі інструменти статичного аналізу:

- **flake8** — перевірка стилю Python-коду та пошук типових помилок.
- **black** — автоматичне форматування коду.
- **mypy** — статична перевірка типів.
- **pre-commit** — запуск перевірок перед створенням коміту.

## Причини вибору

Проєкт написаний мовою Python, тому обрано інструменти, які найчастіше використовуються для Python-проєктів.  
flake8 дозволяє знаходити проблеми зі стилем і потенційні помилки, black уніфікує форматування, mypy перевіряє відповідність типів, а pre-commit не дозволяє додати в репозиторій код із базовими проблемами.

## Базові правила

У файлі `.flake8` встановлено:

- `max-line-length = 120` — максимальна довжина рядка 120 символів;
- `exclude` — ігнорування службових директорій, бази даних, кешу Python та файлів користувача;
- `ignore = E203, W503` — правила, які часто конфліктують із форматером black.

## Ігноровані файли та директорії

Лінтер не перевіряє:

- `.git`
- `__pycache__`
- `.venv`
- `venv`
- `fitness_bot.db`
- `user_files`
- `build`
- `dist`
